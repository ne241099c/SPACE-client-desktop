- [ ] 新規登録 OTP とパスワード再設定が Web と同じ手順で使える。
- [ ] 二重起動時に既存のウィンドウが前に出る。
- [ ] サイズ・位置を変え、終了・再起動して復元される。モニターを外しても画面外に隠れない。

- [ ] Windows の通知許可がオン、集中モードはオフで、別アカウントから返信・DM を送る。
- [ ] フォーカス中は画面のトーストだけで、他のアプリを使っているときは OS 通知が出る。
- [ ] 閉じて1分以上たった後も OS 通知が出る。
- [ ] 通知をクリックするとアプリが前に出て、該当の DM・投稿・通知へ遷移する。
- [ ] 通知と DM の未読数の合計がタスクバーに出る。表示は99で上限、説明は実数。0 で印が消える。

- [ ] ネットワーク切断→復旧、スリープ→復帰後に通知接続が回復する。

## ローカル更新サーバーでの 0.0.1 → 0.0.2

本番の Release を変更せず、使い捨てのローカル作業コピーとテスト用 Windows ユーザーで行う。以下はユーザーが行う検証手順であり、実行済みではない。

1. `npm version 0.0.1 --no-git-tag-version`、`npm run build:electron`。
2. PowerShell で `npx electron-builder --win nsis --x64 --publish never --config.directories.output=release-test-v1 --config scripts/desktop-local-update.cjs`。
3. 同様に 0.0.2 に上げ、出力先を `release-test-v2` として作る。
4. Python が使える環境で `python -m http.server 9081 --bind 127.0.0.1 --directory release-test-v2`。最新 yml と exe が取得できることを確認する。
5. 0.0.1 のインストーラーを実行する。起動時に 0.0.2 が裏でダウンロードされることを確認する。
6. 「再起動して更新」を選び、プロセスが終了して0.0.2で起動することを確認する。ユーザーデータが維持されることも確認する。
7. 更新サーバー停止時は画面を使えて、メニューからの更新確認はエラーを案内することを確認する。
8. テスト版を終了・アンインストールする。配布版の app-update.yml が localhost を含まないことを確認し、テスト用ファイルと本番配布物を混ぜない。

合格条件は実際のインストールと再起動まで。yml の検出やダウンロード開始だけでは合格にしない。
